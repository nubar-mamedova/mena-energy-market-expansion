# MENA Energy Market Expansion

**Status:** In progress · May 2026

## Project goal
Build a multi-criteria scoring model to identify priority cities for energy retail expansion across MENA, using public socioeconomic and infrastructure data.

## Approach
- Data sources: World Bank, IEA, OpenStreetMap, national statistics offices
- Scoring dimensions: market size, urbanization, vehicle ownership, competitor density, regulatory environment
- Tools: Python (pandas, geopandas), Tableau, SQL

## Deliverables
- Cleaned dataset and analysis notebook
- Tableau dashboard with city-level scoring
- One-page recommendation memo

## Timeline
First version: June 2026
